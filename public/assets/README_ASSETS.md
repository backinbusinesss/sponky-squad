# Asset placeholder

Questi file sono placeholder leggeri per rendere la demo completa senza dipendenze esterne.

- `sponky-logo-original.webp`: logo ufficiale scaricato dal tema attuale.
- `community-*.svg`: immagini editoriali temporanee per la gallery. Sostituire con foto/video reali ottimizzati in WebP/AVIF e poster video.
- `italy-map.svg`: base mappa demo. Sostituire con tiles, Mapbox, Leaflet o dati geolocalizzati reali.
- La moto hero carica automaticamente `public/models/superbike.glb`. Se manca, usa un fallback leggero.
- Per HDRI reali usare texture `.hdr` o `.exr` ottimizzate; in questa demo `Environment preset="night"` evita asset pesanti.
